## 1. 目标

在独立原型工程中，**一比一复刻**既有 6Q 测评 App 关键页面（首页 / AQ 年龄 / AQ 答题 / AQ 结果），作为后续需求迭代的视觉与交互基线。

成功标准：

- 主路径可点通：首页 AQ → 年龄 → 3 题答题 → 结果
- 视觉贴近参考截图，风格精美；模块无错位、无横向溢出、弹层不穿出机框
- 元素与交互按设计令牌（claude-design 规范化）约束，便于后续改版

非目标（本期不做）：

- 真实量表题库与计分
- IQ/SQ/CQ/EQ/RQ、心画、分类、「我的测评」等独立子页
- 裁切原截图作为插画资源

## 3. 页面职责

| 页面 | 职责 |
|------|------|
| `index.html` | 6Q 宫格、五分类、心画列表视觉还原；仅 AQ 可进入 `aq-age.html`；其余入口 toast「即将开放」 |
| `aq-age.html` | 插画头图 + 年龄输入（可选）+「开始答题」→ `aq-quiz.html` |
| `aq-quiz.html` | 进度 `n/3`、选项、固定累计用时、底栏「上一题」、末题「提交」、退出确认弹窗 |
| `aq-result.html` | 固定演示分、雷达/正态 Tab、解读卡片、历史/课程/评分反馈；FAB「回首页」「顶部」 |

## 4. 交互状态机

### 4.1 主路径

```
首页 · AQ → 年龄页 → 开始答题 → 题 1/3
  → 点选项（高亮短延迟）→ 题 2/3 → 同理 → 题 3/3
  → 底栏「上一题 | 提交」→ 提交（当前题已选）→ 结果页
```

### 4.2 规则明细

| 场景 | 行为 |
|------|------|
| 年龄 | **可不填**；填写与否不影响演示结果 |
| 累计用时 | **固定**展示 `00 : 15 : 30`，不走动 |
| 选项 | 选中：珊瑚橙字 + 浅橙底；约 180ms 后自动下一题（末题只选中不高跳） |
| 底栏回退（2c） | **每题**显示「上一题」；第 1 题禁用灰显；第 2–3 题可回并恢复已选；末题右侧为「提交」，非末题右侧不显示「下一题」（前进仅靠点选项） |
| 导航返回 | 弹窗文案：**确定要退出测评答题？** / **退出后作答历史将不会保存**；取消关闭；确定回首页且不保存 |
| 提交校验 | 当前题未选 → toast「请选择一项」 |
| 结果数据 | **固定演示**：总分 220、雷达示意、解读/课程占位文案；与选项无关 |
| 结果交互 | Tab 雷达↔正态可切；回首页、回顶可用；星级可点、反馈可填；「提交反馈」toast；课程/历史「去完善」等轻提示 |
| 题量与文案 | **3 题**，进度 `n/3`；题干/选项为占位风格文案，非真实量表 |

### 4.3 退出弹窗视觉

- 白底圆角卡片，居中遮罩（挂在机框内）
- 主文黑体、副文灰字
- 底部分割：左「取消」（灰）、右「确定」（主色橙）

## 5. 视觉令牌（精美向）

| Token | 值 / 约定 |
|-------|-----------|
| 背景 | 暖桃渐变 `#FFF8F4 → #FFEDE5` |
| 主色 | `#FF8A65`；强调 `#FF7A45` |
| 卡片 | 白底；圆角 20–24px；阴影 `0 8px 24px rgba(255,122,69,.08)` |
| 6Q 卡 | 各 Q 独立横向渐变 + 大号半透明字母水印 |
| 字体 | `"PingFang SC", "HarmonyOS Sans", "Noto Sans SC", sans-serif` |
| 插画 | CSS/SVG Q 仔剪影 + 书架线稿，风格统一 |
| 动效 | 选项色过渡、卡片轻 fade-up、结果 FAB 按压缩放（2–3 个，克制） |

参考截图仅作构图与层级依据；插画不裁原图。

## 6. 防错位 / 自检清单

实现完成后必须自检（目标视口 **375×812**）：

1. 所有内容与弹层位于机框屏幕内，不溢出到桌面背景
2. 结果长页仅内容区纵向滚动；无整页横向滚动条
3. 选项长文案不撑破胶囊：允许换行或 `line-clamp`，圆角与左右 padding 保持
4. 6Q 宫格使用 `grid` + `minmax(0, 1fr)`，卡片不互相挤压溢出
5. 底栏按钮、FAB、home indicator 预留安全区
6. 首页 / 答题（含弹窗）/ 结果三态各截一帧人工核对模块对齐
