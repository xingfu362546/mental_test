# 心画测评 H5 版本（人生旅程独立版）设计说明

- 日期：2026-09-02
- 状态：已批准并实现（H5-v1.0.0）
- 产品命名：
  - 旧版：**超级爸妈APP心画测评版本**（根目录现有 v1.0.x 全量链路）
  - 新版：**心画测评H5版本**（仅人生旅程，目录 `h5/`）

---

## 1. 背景与目标

将「人生旅程」从超级爸妈 App 多测评壳中拆出，做成可扫码进入的独立 H5 演示版，与旧版并存。

**本期目标**

1. 新建 `h5/` 子目录，承载 H5 版全部页面与逻辑。
2. 旧版根目录行为保持可完整演示（含 App 首页、构图、AQ、咨询等）。
3. H5 仅人生旅程；无 App 多测评首页。
4. 结果页隐藏课程与咨询（资讯）入口。
5. 扫码再进：按登录用户进度续测或直达解读。
6. 登录按「小程序授权手机号」产品口径；原型用假授权按钮 mock。
7. `index.html` 与 `docs/FEATURES.md` 同步新版本卡片，并写明 H5 **特殊性说明**。

**非目标（本期不做）**

- 真微信/小程序 `getPhoneNumber` 联调、后端账号服务。
- 构图、AQ、咨询在 H5 中的移植。
- 改造旧版 App 首页去隐藏人生旅程（旧版保留入口）。

---

## 2. 方案选择

采用 **方案 1：复制旅程链路进 `h5/` + 本地 mock 账号/进度**。

| 方案 | 结论 |
|------|------|
| 1. `h5/` 独立复制链路 | **采用**：旧版零风险，版本边界清晰 |
| 2. 同页 `?edition=h5` 切换 | 不采用：新旧逻辑缠绕 |
| 3. iframe/重定向回根目录 | 不采用：不像独立产品，状态难管 |

## 4. 登录（mock）

**页面**：`h5/login.html`

- 主 CTA：「微信授权手机号」。
- 点击后 mock 成功，写入会话（`localStorage`），示例字段：

```json
{
  "userId": "mock_13800000000",
  "phoneMasked": "138****0000",
  "loginAt": "ISO-8601"
}
```

- 登录成功后回到 `entry.html` 做分流。
- 正式环境预留：小程序 `getPhoneNumber` → 后端换 `userId`；本期仅占位注释/函数名，不接真接口。

**门禁**：进入 `entry` / 旅程页前若无有效会话 → 跳转 `login.html`。

---

## 5. 进度状态与续测

进度按 `userId` 分桶存 `localStorage`（键名实现时统一，如 `xinhua_h5_progress_{userId}`）。

| status | 含义 | 再进 `entry` |
|--------|------|----------------|
| `none` | 无有效进度 | → `journey-guide.html` |
| `composing` | 已至少生成 1 张图，尚未确认进入解读 | 提示「你上次测试进行中」→ `journey-canvas.html`，恢复描述/成图/剩余重生次数 |
| `completed` | 已进入解读页并落解读结果 | → `journey-result.html` |

**分流顺序**

1. 未登录 → `login` → 回 `entry`
2. 已登录 → 读进度 → 上表跳转
3. `composing`：**先提示再跳转**，禁止静默丢进画板

**进度写入时机（H5 canvas/result）**

- 首次成功生图 → `status=composing`，保存 `lockedDesc`、`imageUrl`、`genCount`、`patternId` 等恢复所需字段。
- 用户确认「去解读」并写入结果 payload → `status=completed`，保存解读展示所需字段。
- 「重新测试」（若提供）：二次确认后清空为 `none`（默认行为）。

**与旧版差异**：旧版继续用现有 `sessionStorage`/`journeyPayload`，不改为账号进度。

## 6. 结果页与导航差异（H5）

**隐藏**

- 「精选课程」区块

**保留**

- 成图、模式名称、常见安排 / 积极面 / 觉察 / 开放式反馈与免责声明

**导航**

- 不链回 `app-home.html`
- 收尾按钮：「完成」和/或「重新测试」（重新测试需确认后清进度）

## 8. 验收用例

1. 版本清单可分别进入 App 全量版与 H5 版，命名正确。
2. H5 未登录进 `entry` → `login` → 授权后 `none` → `journey-guide`。
3. 生图后未进解读，关闭再开 `entry` → 提示进行中 → `canvas` 可续测。
4. 确认进解读后，再进 `entry` → 直达 `result`。
5. `result` 无课程、无咨询；无其它测评入口。
6. FEATURES / index 含 H5 特殊性说明；旧版标题已改为超级爸妈APP命名。

## 10. 已确认决策摘要

- 入口策略 A：H5 不依赖 App 首页；仅人生旅途。
- 目录策略 C：`h5/` 独立子目录。
- 无 H5 营销首页（B）：清单/扫码进 `entry`。
- 结果页藏课程+咨询（B）。
- 续测：已解读 → 结果；已生图 → 提示后 canvas。
- 账号口径 C + 演示 A：小程序手机号授权产品形态 + 假授权按钮。
- 实现架构：方案 1 复制链路。
- 功能清单必须同步并标注特殊性。
